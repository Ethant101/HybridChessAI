# Hybrid Chess AI

A hybrid chess artificial intelligence developed as a Discrete Structures project at Southern Utah University.

## Overview

This project explores how mathematical concepts from discrete structures can be applied to artificial intelligence through the development of a chess-playing algorithm.

The AI will combine game tree traversal, heuristic board evaluation, and intelligent search techniques to determine advantageous chess moves.

## Mathematical Concepts

- Graph theory
- Trees and game trees
- Recursive algorithms
- Minimax search
- Alpha-beta pruning
- Heuristic evaluation

## Planned Features

- Legal chess move generation
- Board position evaluation
- Intelligent move selection
- Configurable search depth
- Performance analysis
- Playable chess interface (optional)

## Technologies

- Python
- Python-chess
- Git and GitHub
